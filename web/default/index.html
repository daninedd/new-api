All-LLMs - Unified API gateway for AI models

All-LLMs provides a unified API gateway and admin dashboard for connecting OpenAI, Claude, Gemini, DeepSeek, Qwen, Llama, and other AI model providers through compatible API routes.

Core features

  • High-performance AI API routing with load balancing.
  • Transparent usage, cost tracking, and billing controls.
  • Team management, API keys, permissions, and rate limits.
  • Self-hostable open-source infrastructure for AI applications.
